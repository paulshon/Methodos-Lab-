Methodos Basic LT-4

按步骤掌握研究用统计

Methodos Basic 是协助分析的自动化程序， 同时按步骤引导操作，提高对统计概念与含义的理解。 通过示例与学习建立概念后，再查看数据、分配变量，并完成分析 → 图表 → 结果。 浅显注释 · 支持韩·英·中，方便留学生使用。

交互式流程指南（Framer Motion）

在浏览器打开落地页，可看到带编号 + 菜单字幕的分步动画。

流程 A

通过示例分析

01 查看数据 → 02 下载格式 → 03 转换 → 04 变量栏 → 05 选变量 → 06 分析 → 07 图表 → 08 结果

流程 B

学习路径

01 名称 → 02 初级 → 03 中级 → 04 高级 → 05 示例验证 → 06 工作台应用

运行：docs-email/guide-landing → npm run dev 或打开 guide-landing/dist/index.html

一句话：下载示例格式并转为自己的数据后，用同一菜单流程完成分析、图表与结果解读。

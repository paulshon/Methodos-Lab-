# methodosG 절차 가이드 (Framer Motion 소스)

홈페이지 게시용 **methodosG** 튜토리얼 소스입니다.  
`Q` 패키지·basic `guide-landing`과 동일한 구조입니다.

## 절차

**A · 자료 → 코딩**  
불러오기(근거자료) → 개방(의미추출) → 축(범주연결) → 선택(이론응축)

**B · 이론화 → 보고**  
메모 → 범주 → 이론 스케치 → 보고서·내보내기

## 구성

- `src/ProcedureShowcase.jsx` — 번호 핀·말풍선·재생 UI
- `src/copy.js` — 한·영·중 (MethodosG-v6 실메뉴 기준)
- `public/shots/` — Desktop 실창 캡처 + 핫스팟
- `dist/` — `npm run build` 산출물

## 실행

```bash
cd G
npm install
npm run dev
```

미리보기: http://127.0.0.1:5182/

## 원본 앱

`MethodosG-v6-portable.exe`를 열어 연구 절차 메뉴를 시현·캡처했습니다.
